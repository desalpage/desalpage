# packages

Released code artifacts of desalpage — snapshots extracted one-way from
the private prototype (`desalpage/fluffy-waffle`). **Never hand-edit
anything in this directory.**

Each extraction appends a record to
[`PROVENANCE.json`](PROVENANCE.json): source repo, source commit, path
mapping, and date. That record is the definitive list of what exists
here; nothing is pre-announced.

npm publishes happen from this repository only — the provenance of a
published version is public here.
