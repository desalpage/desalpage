desalpage is a governance substrate for recursive multi-agent work: agents
delegating down a reporting structure, one bounded sprint at a time —
budgets reserved before delegation, deferrals instead of silence.

## Status

desalpage is developed as a private prototype; this repository is its
public release surface. Posts, papers, and code artifacts appear here as
they are released. Prose on this site is
drafted by AI agents under human direction and review — see
[About](about/).
